한국어 STT 오류율

기준 문장과 음성 인식 결과 한 쌍을 비교합니다. 예제를 고르거나 내 문장을 넣어 보세요.

설치·로그인 없이 이 브라우저에서 계산합니다. 이 페이지는 입력을 전송하거나 저장하지 않습니다.

여러 발화를 파일로 평가하려면

python -m pip install nlptutti==0.0.0.25로 설치한 뒤 nlptutti score ref.txt hyp.txt를 실행하세요. 같은 줄 번호끼리 평가합니다. 이 화면은 한 쌍만 계산하며, 모델의 우열이나 금액·이름의 의미를 판정하지 않습니다.
